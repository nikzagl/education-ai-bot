# LaTeX/MikTeX Setup для образовательного бота

## Описание
Проект использует MikTeX для рендеринга математических формул в изображения. Формулы автоматически преобразуются в красивые PNG изображения через sympy и MikTeX.

## Требуемые компоненты

### 1. MikTeX (для Windows)
Скачайте и установите MikTeX с официального сайта:
- https://miktex.org/download

При установке выберите:
- **Install MikTeX for all users** (опционально, но рекомендуется)
- **Add MikTeX binaries to PATH** ✓ (обязательно!)

### 2. Python пакеты
```bash
pip install sympy pillow mistralai langchain-mistralai
```

### 3. Проверка установки MikTeX

После установки MikTeX проверьте, что команды доступны:
```powershell
# В PowerShell/CMD проверьте:
where latex
where dvipng
where pdflatex
```

Если команды не найдены, добавьте путь MikTeX в PATH переменную:
- Типовой путь: `C:\Program Files\MikTeX\miktex\bin\x64`

## Как это работает

1. **Генерация вопросов**: LLM создает вопросы с LaTeX формулами (например: `$x^2 + 2x + 1$`)

2. **Рендеринг формул**:
   - Sympy использует MikTeX для компиляции LaTeX кода
   - Formulas рендерятся в PNG изображения через `dvipng`
   - Изображения вставляются в финальное изображение вопроса/задачи

3. **Отправка в Telegram**: Красивые изображения с формулами отправляются юзеру

## Примеры LaTeX синтаксиса

- Простая степень: `$x^2$`
- Дробь: `$\frac{a}{b}$`
- Квадратный корень: `$\sqrt{x}$`
- Интеграл: `$\int_0^{1} x dx$`
- Матрица: `$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$`

## Решение проблем

### Проблема: HRESULT 0x80004005 от dvipng
**Решение**: Установите `ghostscript`:
```bash
choco install ghostscript  # Если используете Chocolatey
```

### Проблема: latex/dvipng не найдены
**Решение**: Добавьте папку MikTeX в PATH или переустановите MikTeX с опцией "Add to PATH"

### Проблема: Изображение не рендерится
**Проверьте логи** в консоли бота для деталей ошибки. Обычно это означает:
1. MikTeX не установлен правильно
2. Синтаксис LaTeX неверный
3. Недостаточно памяти для рендеринга

## Note для разработчиков

Функция `render_latex_to_image()` в `utils.py`:
1. Сначала пытается использовать `sympy.preview()` с MikTeX
2. Если не получается, пытается использовать `latex` → `dvipng` напрямую
3. Если оба способа не работают, формула остается как текст `[formula]`
